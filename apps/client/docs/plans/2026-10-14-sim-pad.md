# 시뮬레이션 패드 조작(SW) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SW(core + pad-sim + WinDriver)일 때 시뮬레이션 화면의 패드에서 큐브 끌어 놓기 · 버튼 · 무선 끊김 · 패드 끊김을 흉내 내, HW와 같은 core 흐름을 시험한다.

**Architecture:** 화면 → preload `cubeSpace.sim` → IPC `sim:call` → main `simLink`(pipe `"sim"`) → pad-sim → core. HW/SW 선택은 main이 `userData/source.json`에 저장하고, 바꾸면 core를 새 `--pad` 인자로 다시 띄운 뒤 창을 새로고침한다. 가짜 API는 앱에서 빼고 `test/`에 테스트 대역으로만 남긴다.

**Tech Stack:** Electron · React 19 · react-router · vitest(jsdom) · `@cubespace/protocol/pipe`(named pipe / 유닉스 소켓)

**Spec:** `apps/client/docs/specs/2026-10-14-sim-pad-design.md`

## Global Constraints

- **임시 기능**: 새로 만들거나 크게 고친 부분마다 `HW 통합 후 제거` 주석을 단다. 코드는 최소로, 일반화하지 않는다.
- core 로직(`apps/core`)은 바꾸지 않는다.
- 큐브 id는 스냅샷 `Cube.mac4` = pad-sim `PadCube.id`(예: `A2:F0`).
- 패드 크기: `PAD_W = 200`, `PAD_H = 400 / 3`(mm, `@cubespace/protocol`).
- 기본 선택은 `sw`(pad-gateway가 아직 없다).
- 화면 문구 · 주석 · 커밋 메시지는 한국어. 커밋은 한 줄 `-m`, 접두사만 영어(`feat:` · `fix:` · `refactor:` · `chore:`).
- 명령은 `apps/client`에서 `pnpm test` · `pnpm typecheck` · `pnpm lint`. pad-sim은 `apps/pad-sim`에서 `pnpm test`. WSL에서 typecheck는 2분 넘게 걸릴 수 있다.

## Review Focus

1. **이전 세션 core가 다른 `--pad`로 떠 있음**: client는 떠 있는 core에 그냥 붙으므로 SW인데 pad-sim이 없을 수 있다 → sim 호출은 "pad-sim에 연결할 수 없어요" 토스트로 끝나야 하고, 화면이 멈추면 안 된다(작업 2 simLink 테스트 · 작업 5 실패 토스트 테스트).
2. **패드 끊김 중 조작**: `frozen`이면 끌기 · 메뉴가 꺼져야 한다(`off-ov`가 덮음) → 작업 5 "끊긴 동안 메뉴가 열리지 않는다" 테스트.
3. **패드 밖에 놓기**: 0~1 밖이면 `null`(들기)로 보낸다 → 작업 4 `toPadMm` 범위 밖 테스트.
4. **pad-sim 재시작 뒤 호출**: 패드 끊김 뒤 pad-sim이 새로 뜨면 예전 연결은 닫혀 있다 → 다음 호출에서 다시 붙어야 한다(작업 2 "끊기면 다음 호출에서 다시 붙는다" 테스트).
5. **HW↔SW 전환 직후 새로고침**: core가 재시작되는 동안 창을 새로고침하면 옛 core에 요청이 가 실패할 수 있다 → `restart()`는 새 core에 붙은 뒤에 끝나고, 새로고침은 그다음에 한다(작업 2 ipc 코드. Electron이 필요해 손으로 확인).

```ts
import { readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import type { Source } from "@cubespace/protocol";

// HW 통합 후 제거: 화면이 붙을 곳(HW/SW) 선택. userData/source.json에 둔다.
// 기본 sw: pad-gateway(HW)가 아직 없다
const file = (dir: string) => join(dir, "source.json");

export function readSource(dir: string): Source {
  try {
    return JSON.parse(readFileSync(file(dir), "utf8")) === "hw" ? "hw" : "sw";
  } catch {
    return "sw";
  }
}

export function writeSource(dir: string, v: Source) {
  writeFileSync(file(dir), JSON.stringify(v));
}
```

`apps/client/src/main/simLink.ts`

```ts
import { connect, pipePath, type Conn } from "@cubespace/protocol/pipe";
import type { SimApi } from "@cubespace/protocol";

// HW 통합 후 제거: 시뮬레이션 화면의 가상 패드 조작을 pad-sim(sim pipe)에 넘긴다.
// 처음 부를 때 붙고, 끊기면(pad-sim 재시작) 다음 부를 때 다시 붙는다.
export function createSimLink(path = pipePath("sim")): SimApi {
  let conn: Promise<Conn> | null = null;

  function get() {
    conn ??= connect(path).then(
      (c) => {
        c.onClose(() => (conn = null));
        return c;
      },
      () => {
        conn = null;
        throw new Error("pad-sim에 연결할 수 없어요");
      },
    );
    return conn;
  }

  const req = async (type: string, payload: unknown) => {
    await (await get()).request(type, payload, 3000);
  };

  return {
    moveCube: (id, xy) => req("simCube", { id, xy }),
    press: (id, press) => req("simButton", { id, press }),
    setLink: (id, link) => req("simLink", { id, link }),
    dropPad: () => req("simPad", {}),
  };
}
```

```ts
import { BrowserWindow, ipcMain } from "electron";
import type { ApiMethod, SimApi, Source } from "@cubespace/protocol";
import type { CoreClient } from "./coreClient";
import { readSource, writeSource } from "./source";

// renderer(preload) ↔ core 중계. 호출은 그대로 넘기고, 스냅샷은 모든 창에 밀어준다.
export function relay(core: CoreClient, sim: SimApi, dir: string) {
  ipcMain.handle("core:call", (_, method: ApiMethod, args: unknown[]) =>
    core.call(method, args),
  );
  core.onSnapshot((s) => {
    for (const w of BrowserWindow.getAllWindows())
      w.webContents.send("core:snapshot", s);
  });

  // HW 통합 후 제거: HW/SW 선택 · 가상 패드 조작
  ipcMain.on("source:get", (e) => {
    e.returnValue = readSource(dir);
  });
  ipcMain.handle("source:set", async (_, v: Source) => {
    writeSource(dir, v);
    await core.restart();
    for (const w of BrowserWindow.getAllWindows()) w.webContents.reload();
  });
  ipcMain.handle("sim:call", (_, method: keyof SimApi, args: unknown[]) =>
    (sim[method] as (...a: unknown[]) => Promise<void>)(...args),
  );
}
```

```ts
import { useRef, useState, type PointerEvent } from "react";

// HW 통합 후 제거: 시뮬레이션 패드에서 큐브 끌기 · 탭 판정.
// 누르면 패드 판 위 투명 판(hit)에 포인터를 붙잡는다. Chromium은 눕힌 패드(rotateX)를 풀어
// hit 기준 offsetX/Y를 주므로, 판 크기로 나누면 패드 비율(0~1)이다.
export type Drag = { slot: number; f: [number, number] | null }; // f = 끄는 중 자리(아직 안 움직였으면 null)

export function usePadDrag(
  onDrop: (slot: number, f: [number, number]) => void,
  onTap: (slot: number, el: HTMLElement) => void,
) {
  const hit = useRef<HTMLDivElement>(null);
  const [drag, setDrag] = useState<Drag | null>(null);
  const start = useRef<{ x: number; y: number; el: HTMLElement } | null>(null);

  // 큐브(data-slot)를 감싼 곳에 단다
  function down(e: PointerEvent) {
    const el = (e.target as HTMLElement).closest<HTMLElement>("[data-slot]");
    if (!el || e.button !== 0 || !hit.current) return;
    e.preventDefault();
    hit.current.setPointerCapture?.(e.pointerId);
    start.current = { x: e.clientX, y: e.clientY, el };
    setDrag({ slot: Number(el.dataset["slot"]), f: null });
  }

  function move(e: PointerEvent<HTMLDivElement>) {
    const s = start.current;
    if (!s || !drag) return;
    if (!drag.f && Math.hypot(e.clientX - s.x, e.clientY - s.y) <= 4) return;
    const h = e.currentTarget;
    setDrag({
      slot: drag.slot,
      f: [
        e.nativeEvent.offsetX / h.clientWidth,
        e.nativeEvent.offsetY / h.clientHeight,
      ],
    });
  }

  function up() {
    const s = start.current;
    start.current = null;
    setDrag(null);
    if (!s || !drag) return;
    if (drag.f) onDrop(drag.slot, drag.f);
    else onTap(drag.slot, s.el);
  }

  function cancel() {
    start.current = null;
    setDrag(null);
  }

  // hit 판에 펼친다
  const hitProps = {
    ref: hit,
    onPointerMove: move,
    onPointerUp: up,
    onPointerCancel: cancel,
  };
  return { drag, down, hitProps };
}
```

```tsx
  cube: Cube;

export function CubeMenu({ cube, at, onPick, onClose }: Props) {
  const ref = useRef<HTMLDivElement>(null);

  // Esc · 바깥을 누르면 닫는다
  useEffect(() => {
    const key = (e: KeyboardEvent) => e.key === "Escape" && onClose();
    const out = (e: globalThis.PointerEvent) =>

    document.addEventListener("keydown", key);
    document.addEventListener("pointerdown", out);
    ref.current?.querySelector("button")?.focus();
    return () => {
      document.removeEventListener("keydown", key);
      document.removeEventListener("pointerdown", out);
    };
  }, [onClose]);

    ["short", "버튼 짧게"],

      ref={ref}
      className="cmenu"
      role="menu"
      aria-label={`큐브 ${cube.name}`}
      style={{ left: at.x, top: at.y }}
```

```tsx
  const { drag, down, hitProps } = usePadDrag(
    (slot, [fx, fy]) => run(sim!.moveCube(mac(slot), toPadMm(fx, fy))),
    (slot, el) => openMenu(slot, el),
  );
  function openMenu(slot: number, el: HTMLElement) {
    const r = el.getBoundingClientRect();
    setMenu({ slot, x: r.left, y: r.bottom + 6 });
  }
  // 키보드(Enter · Space)로 누른 때만. 마우스 · 터치는 usePadDrag의 탭이 연다
  const keyOpen = (slot: number) => (e: { detail: number; currentTarget: HTMLElement }) =>
    live && e.detail === 0 && openMenu(slot, e.currentTarget);
  function pick(a: CubeAction) {
    const c = s.cubes.find((x) => x.slot === menu!.slot)!;
    setMenu(null);
    if (a === "link") run(sim!.setLink(c.mac4, c.link === "up" ? "down" : "up"));
    else run(sim!.press(c.mac4, a));
  }
  const menuCube = live && menu ? s.cubes.find((c) => c.slot === menu.slot) : undefined;
  const dragged = drag?.f ? s.cubes.find((c) => c.slot === drag.slot) : undefined;
```
